# Tarea 2: CSS — Dale estilo a tu sitio

Proyecto de CSS incremental donde se aplican selectores, pseudoclases, pseudoelementos y combinadores sobre una plantilla HTML. Tema: café de especialidad.

## Archivos

- `proyecto.html` — archivos principales (ejercicios 2-8)
- `Ejercicio1.html` — ejercicio 1 (3 métodos de inclusión CSS)
- `estilos.css` — hoja de estilos compartida

## Ejercicios

| # | Ejercicio | Tema |
|---|-----------|------|
| 1 | Los 3 métodos de inclusión | Inline, interno, externo |
| 2 | Selectores básicos | Universal, etiqueta, clase, ID |
| 3 | Especificidad | Conflicto de estilos y resolución |
| 4 | Selectores de atributos | Existencia, valor exacto, lista |
| 5 | Selectores de subcadenas | Comienzo, contiene, final |
| 6 | Pseudoclases | hover, focus, checked, nth-child |
| 7 | Pseudoelementos | before, after, first-letter, first-line |
| 8 | Selectores combinadores | Descendiente, hijo, hermano |

## Cómo abrir

Abre `proyecto.html` o `Ejercicio1.html` directamente en tu navegador.
