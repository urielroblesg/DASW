### 01-HTML / Introduccion

Fundamentos de HTML5: estructura de un documento, etiquetas de texto, listas, tablas, imágenes, enlaces y formularios.

- **01_mi_primera_pagina.html** — Primera página web: estructura HTML5 (`doctype`, `head`, `body`), encabezados, párrafos con negritas e itálicas, listas ordenadas y desordenadas, entidades HTML y comentarios.
- **02_portal_peliculas.html** — Portal de películas: imágenes, enlaces externos e internos (anclas), tablas con celdas combinadas (`colspan`/`rowspan`), formularios con validación y envío por correo, y contenedores `div`.
- **03_reto_portafolio_personal.html** — Reto: construir un portafolio personal sin estructura prestablecida, aplicando encabezados, listas, negritas, itálicas y pie de página.
- **04_desafio_catalogo_videojuegos.html** — Desafío integrador: catálogo de videojuegos que combina todo lo aprendido (imágenes, enlaces, tabla comparativa y formulario de reserva).

### 02-CSS / Introduccion

Introducción a CSS: formas de aplicar estilos, selectores y primeros proyectos estilizados.

- **01_tres_formas_css.html** — Las 3 formas de agregar CSS: inline (atributo `style`), interno (etiqueta `<style>`) y externo (archivo `.css` con `<link>`).
- **02_tarjetas_estilos_css.html** — Tarjetas estilizadas practicando los 3 métodos de inserción de CSS.
- **03_portfolio_selectores_css.html** — Portfolio personal que aplica selectores de clase (`.`), ID (`#`) y CSS externo para destacar contenido.
